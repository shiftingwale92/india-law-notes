# india-law-notes

Plain-language notes on Indian law, mainly technology, privacy and commercial regulation. Each note quotes or closely follows the primary text and links its sources.

**These notes are educational material, not legal advice.** Laws and rules change; every note states the version and date checked. Verify the current text before relying on anything.
